# MeshCentral Script Runner 0.1.0

Экспериментальный плагин для запуска PowerShell на выбранных устройствах Windows через штатные команды и файловый канал MeshCentral. MeshCore не изменяется. Кнопка находится рядом с массовой установкой Zabbix, когда установлен Zabbix Installer.

Версия 0.1 обрабатывает устройства последовательно. Окно браузера должно оставаться открытым. Таймаут ограничивает ожидание результата, а не останавливает процесс; при потере связи или таймауте результат неизвестен, и очередь останавливается. Проверьте состояние устройства перед повтором. История, пресеты, теги, экспорт, параллельное выполнение и Linux пока не реализованы.

Скрипты выполняются от учётной записи службы агента. Временные файлы размещаются в `C:\Windows\System32\config\systemprofile\AppData\Local\Temp\BulkScriptRunner`. Перед передачей проверяются права каталога и его родительских папок. После завершения процесса плагин пытается удалить два созданных файла `.ps1`; журналы и файл результата остаются. При сбое процесса, выключении устройства или ошибке очистки скрипты могут остаться. Ошибка очистки отображается в результате. При ошибке передачи до запуска частично переданные файлы также могут остаться. Плагин не удаляет другие файлы.

Для установки в менеджере плагинов MeshCentral используется URL `https://raw.githubusercontent.com/Sokol549/meshcentral-script-runner/main/config.json`. Нужны права полного администратора MeshCentral и права на команды и файловый доступ к выбранным устройствам.
